# Dark Theme + 3D Hero Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-theme the whole KregKreates site dark (`#0a0a0a`, accent `#39FF88`) and replace the Home hero panel with a Three.js workflow-node network driven by mouse, scroll and a GSAP load sequence.

**Architecture:** The dark theme is a token swap in `assets/styles.css` plus per-use overrides wherever the old ink color was a fill. The hero gets three ES modules. `hero.js` is the entry point and handles fallbacks and lifecycle. `hero3d.js` holds the Three.js scene. `hero-motion.js` holds the GSAP load and scroll animations. Three.js and GSAP come from jsDelivr through an import map on `index.html` only. A scratchpad harness proves each task.

**Tech Stack:** HTML, CSS, vanilla ES modules with `// @ts-check` + JSDoc, Three.js `0.170.0` (+ `RoomEnvironment` addon), GSAP `3.13.0` + ScrollTrigger. Harness only: puppeteer-core 23 + installed Chrome, pngjs, TypeScript 5 with `@types/three@0.170`, html-validate 9.

**Spec:** `docs/superpowers/specs/2026-10-06-dark-3d-hero-design.md`

## Global Constraints

- Branch `dark-3d-hero`. Never stage `README.md` (the owner's pending deletion); stage explicit paths only.
- No build step and no npm dependencies in the repo. The only new external runtime requests are jsDelivr: `three@0.170.0`, `three@0.170.0/examples/jsm/`, `gsap@3.13.0` (`index.js`, `ScrollTrigger.js`).
- All copy, links, photos and page structure stay. The only structural change is in the Home hero.
- Palette (spec table, verbatim): background `#0a0a0a`; alternate section `#0f1110`; surface `#141716`; text `#EDEFEC`; muted `#A3A8A4`; subtle `#7C827E`; rule `rgba(255,255,255,.08)`, strong `rgba(255,255,255,.16)`; accent `#39FF88`, pressed `#2BE076`, on-accent `#0a0a0a`; grid `rgba(57,255,136,.06)`; glass `rgba(255,255,255,.04)` + `1px rgba(255,255,255,.10)` + `blur(16px) saturate(140%)`; glow `0 0 0 1px rgba(57,255,136,.6), 0 0 32px rgba(57,255,136,.45)`; lifted card `0 8px 32px rgba(57,255,136,.18)`.

- Hero copy never depends on JS, WebGL or the CDN. No CSS hides it; GSAP only animates `from` a hidden state.
- The pixel-match gate against the Framer site (`gate.py`) is retired.

## Review Focus

1. **Back/forward navigation (bfcache)**: returning to Home shows a live, rendering network, not a dead canvas. → Task 3 `bfcache`.
2. **Resize, rotation, high-DPI**: the canvas always matches the hero size, its pixel ratio is capped at 2 (1.5 on phones), and nothing stretches. → Task 3 `resize-dpr`.
3. **Phones**: the network behind the copy must not make text hard to read, and touch must not trigger mouse tilt. → Task 3 `phone-scrim`. Touch tilt is guarded by binding the pointer only for `(pointer: fine)`.
4. **CDN slow or down**: the page stays fully usable with no uncaught errors. → Task 3 `cdn-blocked`.
5. **Reduced motion**: one static frame, then no rendering, no stagger and no scroll motion. → Task 3 `reduced-static` (scene) and Task 4 (no stagger).
